# Тестовые материалы для импорта

Эта папка лежит в корне проекта и предназначена только для ручной проверки экрана `Материалы`.

Здесь собраны пять новых примеров, написанных специально под текущий локальный импорт:

- короткие и чистые абзацы без шумной разметки;
- заметные даты, названия, географические объекты и термины;
- длина предложений, удобная для текущего генератора черновых вопросов;
- нейтральный, спокойный и конкурсный русский текст.

Состав папки:

- `01_altai_route_basics.txt` — базовый обзор по ключевым точкам и смыслу маршрута.
- `02_barnaul_story.md` — пример Markdown с заголовками и связным историческим текстом.
- `03_chuysky_tract_notes.txt` — транспортный и туристический материал с точными формулировками.
- `04_museum_and_stonecutting.md` — культурный блок про камнерезное дело и музеи.
- `05_science_and_nature_reference.txt` — научно-природный материал с именами и объектами.

Как проверять:

1. Открой `Материалы`.
2. Импортируй любой файл из этой папки.
3. Убедись, что draft получает внятное название, разделы и набор редактируемых вопросов.
4. При желании выключи часть разделов и пересобери вопросы.

Эти файлы не являются готовой викториной. Это именно хорошие исходники, из которых текущий конструктор должен собирать аккуратный черновик набора.
