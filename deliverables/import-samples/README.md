# Import Samples

- `structured_notes.txt` - ровный текст с короткими разделами и фактами.
- `history_article.md` - Markdown с заголовками, списками и подзаголовками.
- `travel_digest.pdf` - многостраничный PDF для проверки извлечения текста.
- `museum_overview.docx` - DOCX с абзацами и базовой структурой документа.
- `messy_reference.txt` - шумный файл с повторами, короткими строками и смешанными фрагментами.

Все файлы можно загружать в экран `Материалы` для проверки локального конструктора и ручной доработки черновика.
