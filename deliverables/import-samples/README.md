# Import Samples

Вся тестовая выборка для экрана `Материалы` лежит в одной папке:

- `structured_notes.txt` - аккуратный линейный текст с короткими разделами и явными фактами.
- `history_article.md` - Markdown с заголовками, списками и подзаголовками.
- `travel_digest.pdf` - PDF для проверки извлечения текста из многостраничного документа.
- `museum_overview.docx` - DOCX с обычными абзацами и базовой структурой документа.
- `messy_reference.txt` - шумный stress-case с повторами, короткими строками и смешанными фрагментами.

Поддерживаемые форматы импорта в приложении:

- `TXT`
- `MD`
- `PDF`
- `DOCX`

Здесь лежит 5 тестовых файлов: четыре покрывают все поддерживаемые форматы, а второй `TXT` нужен как отдельный сценарий грязного исходника для ручной чистки и пересборки черновика.
