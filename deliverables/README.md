# AuraNode Deliverables

- `app-release.apk` - release build for contest submission
- `app-debug.apk` - debug build for local verification

Suggested review flow:

1. Launch the app and keep the default Altai route for the strict contest path.
2. Start `Classic` on any difficulty and complete one run.
3. Open the interactive `Atlas` and inspect unlocked nodes and routes.
4. Return to the menu and test `Import Material`.
5. Load a `txt`, `md`, `pdf`, or `docx` file and generate a custom quiz pack.

Screenshots can be placed in `deliverables/screenshots/` if you want to attach a visual set to the repo later.
