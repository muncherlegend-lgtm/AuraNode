# AuraNode Deliverables

- `app-release.apk` — release build for contest submission
- `app-debug.apk` — debug build for local verification

Suggested review flow:

1. Open the app and keep the default Altai route for the strict competition path.
2. Try `Classic` on any difficulty.
3. Return to menu and test `Import Material`.
4. Load a `txt`, `md`, `pdf`, or `docx` file and generate a custom quiz pack.

Screenshots can be placed in `deliverables/screenshots/` if you want to attach a visual set to the repo later.
